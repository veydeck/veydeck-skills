# Veydeck PNG 图标家族

将一组语义不同的图标做成可持续扩展的视觉家族。先识别用户批准的基准和实际显示尺寸，再生成；不将应用入口 256px 规格套到用户指定的文件图标上。

## 设计与生成

- 阅读 [品牌规范](references/veydeck-brand.md)；需要匹配文件管理 v01 时读 [v01 模板](references/file-family-v01.md)。最终资产属于消费项目，不放进技能仓库。
- 从消费仓选择已确认的图标作为风格参考并查看。记录类型、名称、后缀、主要对象、强调色、导出尺寸与状态；分类和具体后缀映射分开。
- 新家族先做少量样图供视觉选择；已有明确批准的风格时按该基准扩展，不机械要求每个图标生成多个候选。
- 默认使用可用的内置 `image_gen`，一类资产一次调用，开启透明背景。如果环境提供 `imagegen` skill，遵循其工具用法；工具不可用时说明阻塞，不擅自改用付费 API。
- 参考图仅约束材质、光源、边缘与视觉重量，提示词明确本次语义，避免复刻参考图中的符号。文件类型可共享文件页，侧边导航通常使用独立轮廓。
- 每个图标使用一个主要对象和少量粗壮特征；不要靠微小后缀文字辨认。统一左上柔光、轻量立体、透明留白，不使用地面阴影、背景板、文字水印或品牌商标。
- 使用原生工具返回的来源路径复制原图并留在默认位置；不覆盖旧版本。分批调用期间保存每个完成结果，单个失败仅重试该项。

## 导出与检查

准备一份 JSON 清单，示例见脚本命令下方。使用内置工具生成图片；本脚本只做确定性缩放、预览和归档，不替代图像编辑工具。

```bash
uv run scripts/prepare_family.py catalog.json /path/to/output --size 240 --content 200
```

清单是数组，每项包含 `id`、`name`、`source`（生成原图路径）、`prompt`（完整提示词），可选 `status` 和 `reference`；`id` 使用含版本的安全文件名，例如 `file-capture-v01`。使用绝对来源路径，或相对于清单目录的路径。

脚本保存 `originals/`、`exports/`、`prompts/`、`previews/` 和 `manifest.json`。已有同名资料内容不一致时停止，改用新版本名；不会覆盖原图或误将一半新图混进旧清单。默认输出 20／32／48／64px 原生尺寸对照，主体等比放入 200px 范围，四角透明。

- 先检查真实显示尺寸，再看大图。20px 下确认主要轮廓、符号和颜色能区别，不只看精美的大图。
- 查看明暗背景，检查透明通道、边缘、留白、光源和重量。角标要另做叠加预览，不能替代文件主类型。
- 色彩或形状需修改时通过图像生成工具另存版本，不用脚本重绘。
- 交付总览、实际尺寸预览及留档目录。生成资产并不表示获准修改界面或部署。

## 归档与接入

```bash
uv run scripts/prepare_family.py --pack /path/to/output --zip /path/to/family-v01.zip
```

归档不覆盖已有 ZIP；内含相对路径和 SHA-256 校验清单，写完校验 ZIP CRC、文件数量及每个文件的内容后生成 `.zip.sha256`。

扩展既有归档时先验证旧校验文件；在临时目录展开，将新增版本合并并更新总清单，避免 ZIP 同名条目和清单遗漏。写入新 ZIP 后逐一比较原有条目的内容（允许更新的说明和清单除外），通过后才按用户要求替换原包。用户未要求合并或替换时，另存新版本。不要自动访问 NAS 或清理过程资料；用户确认归档完成并要求清理后才删除对应生成资料，保留运行时资产。

接入获得授权后，使用消费仓现有资源管线：后缀大小写归一化、复合后缀优先、目录类型优先于名称、未知类型兜底。链接类型基于已有事实，不为图标逐项发起请求；后缀歧义明确选择规则（如 `.ts` 优先源码）。提供存在的稳定或内容哈希 URL，并保留无障碍名称与非拖拽的装饰图片。运行消费仓要求的测试、format、lint、类型检查及构建；部署须有用户授权。
