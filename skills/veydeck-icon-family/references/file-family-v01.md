# 文件管理 v01 家族模板

这是一套已确认的示例基准，不是所有项目都必须采用的规则。需要匹配时由消费仓提供已确认 PNG，不在 skill 中复制业务资产。

- 文件：中亮蓝灰折角页，略圆边缘，单个大号立体符号；目录为琥珀文件夹。
- 侧边导航：房屋、根盘、星标、吊牌等独立轮廓，与文件页区分。
- 材质：柔和圆润的轻量立体，克制高光，左上柔光；保留批准版本的质感，不能自行换成扁平或哑光。
- 文件图标规格：240 × 240px、RGBA；主体等比放入 200 × 200px，实际使用 20px，兼看 32／48／64px。
- 主体避免接近纯黑；在深色与浅色背景上都要清楚，不加地面、投影或环境。

## 提示词骨架

```text
Generate exactly ONE standalone PNG icon on a true transparent RGBA background.
The attached image is a STYLE REFERENCE only: match its blue-slate material,
rounded bevels, softly raised symbols, upper-left soft light and visual weight.
Do not reproduce the reference symbol. Keep a near-front orthographic view,
one dominant object, simple bold geometry and clear readability at 20px.
Center the full silhouette with generous transparent margins.
No scene, background tile, ground shadow, watermark, vendor logo or tiny text.
SUBJECT: [具体对象、语义、强调色；是否保留文件页；排除易混淆的形状]
```

目录／脚本样图先确认后再扩展是一种已验证的协作方式。不要将“塑料感更少”自动理解为改成扁平；以用户最终选中的版本为准。

网络抓包可用青色数据包流，种子可用绿色分发节点，电子书可用紫色打开书本。收藏夹和标签资产预先生成不表示应创建相应产品功能。
